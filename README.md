# Парсер карточки персоны OBD Memorial

Скрипт для автоматического извлечения данных с карточки персоны сайта **ОБД Мемориал** (obd-memorial.ru) с помощью **Puppeteer** (безголовый Chrome) и сохранения в CSV.

## 🚀 Использование

```bash
node index.js "https://obd-memorial.ru/html/info.htm?id=..."
```

Скрипт:
1. Открывает страницу карточки персоны в безголовом Chrome
2. Ожидает полную загрузку страницы (с паузами для щадящей нагрузки на портал)
3. Извлекает все доступные данные
4. Сохраняет результат в CSV-файл в папку `data/`

## 📁 Состав репозитория

- `index.js` — основной скрипт для Puppeteer
- `test.js` — тестовый скрипт проверки работы Puppeteer
- `на_странице_карточки_персоны_OBD_Memorial.txt` — оригинальный скрипт для выполнения в консоли браузера (F12)
- `data/` — папка для сохранения CSV-файлов (создаётся автоматически)

## ⚙️ Технические детали

- **Puppeteer** — управление безголовым Chrome
- **Задержки** — между действиями проставлены паузы (3 сек после загрузки, 1 сек перед закрытием), чтобы не создавать избыточную нагрузку на портал
- **CSV** — сохраняется с кодировкой UTF-8 (BOM) для корректного отображения кириллицы
- **Вывод** — файл сохраняется в папку `data/` с именем `person_{id}.csv`
