# puppeteer-project — парсер OBD Memorial через Edge CDP

Парсер карточек персон сайта **ОБД Мемориал** ([obd-memorial.ru](https://obd-memorial.ru)).

Работает **не** через безголовый Chrome, а через подключение к уже запущенному **Microsoft Edge** по протоколу **CDP** (remote debugging). Edge запускается отдельным процессом.

## Требования

- Windows 10 (рабочий ПК)
- Node.js **24.5.0** (зафиксировано в `.nvmrc`)
- Microsoft Edge
- PowerShell 7+

## Установка

```powershell
npm install
```

> Puppeteer используется только как CDP-клиент (без скачивания своего браузера).
> При установке можно пропустить загрузку Chromium:
> ```powershell
> $env:PUPPETEER_SKIP_DOWNLOAD="true"; npm install
> ```

## Запуск

### 1. Поднять Edge с CDP

```powershell
pwsh scripts/RunEdgeOBD.ps1
```

Скрипт:
- ищет `msedge.exe` в стандартных путях;
- создаёт/использует профиль `user_01` **вне репозитория**;
- чистит только кэши (Cache/GPUCache и т.п.);
- запускает Edge с `--remote-debugging-port=9226`;
- открывает obd-memorial.ru.

### 2. Запустить парсер

```powershell
node obd-edge.js          # полный прогон
node obd-edge.js --dry-run # только показать обработку, ничего не писать
node obd-edge.js --port=9227  # другой порт
```

## Что делает парсер

1. Читает список URL из `data/raw/input_urls.txt` (по одному адресу на строку; `#` — комментарий).
2. Последовательно открывает карточки через подключённый Edge.
3. Извлекает данные из элементов `.card_parameter`.
4. Разделяет результат на два CSV.
5. Пишет логи сессии и ошибок.

## Типы карточек

Парсер учитывает два типа страниц obd-memorial.ru:

| Тип | Особенности |
|---|---|
| «Информация из документов, уточняющих потери» | есть «Причина выбытия», «Дата выбытия», «Первичное место захоронения» |
| «Информация из списков захоронения» | нет «Причины выбытия»; есть «Дата смерти», «Место захоронения», «Откуда перезахоронен» |

Дата гибели берётся из «Дата выбытия» или «Дата смерти». Захоронение — из «Место захоронения» (fallback — «Первичное место захоронения»).

## Логика разделения «убит/погиб» (свежая редакция)

1. Причина выбытия содержит «убит» или «погиб» → **killed**.
2. Причина не указана, но есть «Дата смерти» и захоронение (первичное/место) → **killed** (погибший из списка захоронения).
3. Остальные случаи → **other** (причина/особенности уходят в `notes`).

## Выходные файлы

Папка `data/processed/logs/` (создаётся автоматически):

- `{YYYY-MM-DD}__parser_mem2026.csv` — убит/погиб
- `{YYYY-MM-DD}__other_mem2026_.csv` — остальные причины
- `{YYYY-MM-DD}__session.log` — полный лог
- `{YYYY-MM-DD}__errors.log` — только ошибки

CSV — UTF-8 с BOM.

## Возобновление после краша

Скрипт ведёт журнал `data/processed_urls.txt`. При перезапуске уже обработанные URL пропускаются.

## Структура

```
puppeteer-project/
├── obd-edge.js                 # основной парсер (Edge CDP)
├── scripts/
│   ├── RunEdgeOBD.ps1          # запуск Edge c CDP (user_01, 9226)
│   ├── launch.json             # VS Code attach к Edge 9226
│   ├── settings.json           # настройки workspace
│   └── extensions.json         # рекомендуемые расширения
├── data/
│   ├── raw/input_urls.txt      # список адресов для парсера
│   ├── processed_urls.txt      # журнал обработанных URL
│   └── processed/logs/         # результаты и логи
├── archive/                    # предыдущая реализация (legacy)
└── .nvmrc                      # фиксация Node 24.5.0
```
