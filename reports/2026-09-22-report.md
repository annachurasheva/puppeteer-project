## 3. Ключевые решения

1. **Edge CDP вместо безголового Chrome.** `obd-edge.js` подключается к уже запущенному Edge (`puppeteer.connect` на `localhost:9226`). Запуск Edge — `scripts/RunEdgeOBD.ps1` (профиль `user_01`, вне репо).
2. **Только obd-memorial.ru.** ok.ru-инструменты и мульти-профили убраны в `archive/`.
3. **Гибкий ввод:** любые `.txt` в `data/raw/` (без жёсткой привязки к `input_urls.txt`); имя файла осмысленное (например, `links_id_398_сд_03_1942_крым.txt`).
4. **Результаты и логи** — `data/processed/<имя_файла>/`.
5. **Глобальная сумма** `data/summary/processed_ids.txt` — накопитель id по всем файлам; контроль «не ходить повторно».
6. **`scripts/check-input.js`** — контроль перед стартом: дубли внутри файла, уже обработанные (журнал + сумма), сколько новых.
7. **Два типа карточек** obd-memorial: «документы, уточняющие потери» + «списки захоронения» (синонимы полей: `Дата выбытия`/`Дата смерти`, `Место захоронения`/`Первичное место захоронения`).
8. **Свежая классификация «убит/погиб»:** причина содержит «убит/погиб» **или** (нет причины + есть «Дата смерти» + есть захоронение) → killed.
9. **Рандомизация задержек:** после загрузки 3–6 сек, между карточками 3–15 сек.
10. **Node 24.5.0** зафиксирован в `.nvmrc`; `package.json` — main/scripts/engines.
11. **`.gitattributes`** — добавлены `*.log`, `*.csv` как текст (LF).
